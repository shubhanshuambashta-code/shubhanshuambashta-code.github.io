# Shubhanshu Ambshta — Portfolio

A lightweight, responsive portfolio site built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and metadata
- `styles.css` — responsive visual styling
- `script.js` — project filters, navigation, and rendering
- `content.js` — editable profile, projects, skills, and experience
- `favicon.svg` and `social-card.svg` — site identity assets

## Update portfolio content

Edit `content.js` and commit the changes to `main`. Project details, profile text, skills, links, and experience are stored there.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages will publish this personal site at:

https://shubhanshuambashta-code.github.io/
